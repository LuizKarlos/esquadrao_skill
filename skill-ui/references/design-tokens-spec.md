# Design Tokens Specification

Hierarchical structure for consistent, accessible UI design tokens.

## Token Categories

1. **Colors**:
   - `color-surface-bg`: Background surface color.
   - `color-surface-fg`: Foreground high-contrast text color.
   - `color-interactive-primary`: Accent and primary button color.
2. **Spacing & Sizing**:
   - `space-xs`: 4px
   - `space-sm`: 8px
   - `space-md`: 16px
   - `space-lg`: 24px
   - `target-min`: 44px (minimum touch target)
3. **Typography**:
   - `font-size-base`: 16px (rem 1.0)
   - `line-height-base`: 1.5
