# Fontes empacotadas

Estas fontes são distribuídas com o `@esquadrao/cli` para que os templates de legenda tenham o mesmo desenho em qualquer sistema.

| Arquivo | Família | Origem | Licença |
| :--- | :--- | :--- | :--- |
| `Anton-Regular.ttf` | Anton | [Google Fonts](https://fonts.google.com/specimen/Anton) | SIL Open Font License 1.1 |
| `BebasNeue-Regular.ttf` | Bebas Neue | [Google Fonts](https://fonts.google.com/specimen/Bebas+Neue) | SIL Open Font License 1.1 |
| `Poppins-Bold.ttf` | Poppins | [Google Fonts](https://fonts.google.com/specimen/Poppins) | SIL Open Font License 1.1 |

O texto integral da licença está em [`OFL.txt`](./OFL.txt).

Liberation Sans Bold e DejaVu Sans Mono Bold são resolvidas do sistema operacional; quando ausentes, o CLI usa `Poppins-Bold.ttf` como fallback.
